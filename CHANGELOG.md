# Changelog

Sunshot follows [semantic versioning](https://semver.org). Versions are listed newest first; the version of a build
is in `VERSION` and in Settings ▸ About.

## 0.1.0 — 2026-11-18

The first public release of Sunshot, a lightweight native screenshot beautifier for macOS 26 and later.

### Beautify
- Open, drop or paste an image (PNG, JPEG, HEIC, TIFF, WebP) onto a canvas with a backdrop and padding.
- Backdrops: none, solid, gradient (with editor) or image; blur, noise, patterns, vignette, overlay textures and
  auto backgrounds made from the screenshot's own colours.
- Corners, borders and shadows with a light-source handle; window, card, stack and border frames in light or dark.
- Position, tilt and layout presets; multiple screenshots in one layout; device mockups and a template gallery.
- Code snippets with syntax highlighting and themes.
- Annotate: pen, highlighter, arrows, shapes, text, step counters, blur and pixelate redaction, stickers.
- Animate a layout and export it as video.

### Capture and export
- Capture an area, a window (hover to pick) or a website; global shortcuts (⇧⌘S, ⇧⌘W, ⇧⌘0) that work from the
  menu bar, with captures copied already styled with your default style.
- Export PNG, JPEG or HEIC at any size and scale, copy to the clipboard, and batch-export many screenshots at once.
- Documents with autosave, Open Recent, undo and redo for every change.

### Updates
- Sunshot ▸ Check for Updates…, and an automatic check once a day (Settings ▸ About; can be turned off). Sunshot
  asks GitHub for the latest version number only; Download opens the release page.

### Known limitations
- The app is not notarised yet: the first time you open it, Control-click Sunshot in Applications and choose Open.
- Updates are not installed automatically: download the new version and replace Sunshot in Applications.
