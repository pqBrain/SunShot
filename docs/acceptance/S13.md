# S13 — Animate & video export — acceptance criteria

Conventions: the animation is a **timeline** stored in the document (`Project.animation`): a lead-in (default 500 ms)
followed by **keyframe clips** played one after another. Each clip animates the S6 content transform
(`x, y, zoom, rotation, tiltX, tiltY`) from the previous state to the clip's **target** over its **duration**
(0…10 000 ms, default 1000 ms; 0 = **jump cut**) with an **easing** (`spring` default, `linear`, `cubic`, `out`,
`inOut`, `outCirc`), then holds the target for the clip's **hold** (0…10 000 ms, default 500 ms). The start state is
the document's own transform (`Project.placement.transform`). The total length is the longer of the timeline and the
video content, capped at **2 minutes**. Content is a still image, a code snippet or a **video** (imported with
AVFoundation, ≤ 2 min). Every video frame is `Renderer.render(document:)` of the document with the interpolated
transform and (for video content) that moment's video frame: the same render function as preview and image export.
Video export options: resolution 720p / HD / 2K (= 720 / 1080 / 1440 px on the canvas's shorter side, even
dimensions, ≤ 4096 px per side), 30 or 60 fps, H.264 or HEVC in `.mp4`; a see-through backdrop exports HEVC with
alpha in `.mov`.

## S13-AC1 — No animation leaves the document unchanged
Given a document that never used Animate
When it is rendered, encoded and decoded
Then the render is byte-identical to before S13, the encoded `Project` has no `animation` key, and a document
without the key decodes with an empty timeline (lead-in 500 ms, unmuted, HD / 30 fps / H.264)
Test level: unit

## S13-AC2 — Interpolation is exact at the keyframes
Given a timeline with clips A (1000 ms) and B (600 ms) from start transform S
When `transform(at:)` is evaluated
Then it returns S up to the end of the lead-in, exactly A's target at A's end and through A's hold, exactly B's
target at B's end and after it, and values in between lie between the two keyframes for monotonic easings
And evaluating the same time twice gives the same transform (pure, deterministic)
Test level: unit

## S13-AC3 — Easing curves
Given the six easings
When each is sampled on 0…1
Then each starts at exactly 0 and ends at exactly 1
And linear, cubic, out, in-out and out-circ are monotonic non-decreasing and stay within 0…1
And spring overshoots by at most 8 % and settles within 2 % of 1 from 80 % of the clip on
Test level: unit

## S13-AC4 — Jump cut
Given a clip with duration 0
When the timeline is evaluated just before and at the clip's start
Then the transform switches from the previous state to the clip's target with no frames in between
Test level: unit

## S13-AC5 — Editing clips is undoable
Given a document with content
When the user adds a clip at the playhead, removes a clip, moves a clip earlier or later, changes its easing,
duration, hold or target, or toggles mute
Then each is exactly one undo entry with a named action ("Add Animation", "Delete Animation", "Move Animation",
"Change Easing", "Change Duration", "Change Hold", "Change Animation Target", "Mute Audio"/"Unmute Audio"), and
changes that change nothing record nothing
And a new clip is inserted after the clip under the playhead, with duration 1000 ms, spring easing and a target
zoomed in 20 % from the state at that point
Test level: unit

## S13-AC6 — Two-minute limit
Given clips whose durations add up to more than 2 minutes, or video content longer than 2 minutes
When the total length is computed, or the video is imported
Then the length is capped at 120 s, and a video longer than 120 s is refused with "Videos can be at most 2 minutes
long" and the document is unchanged
Test level: unit

## S13-AC7 — Importing video content
Given a movie file with a video track
When it is imported
Then the document content becomes the video (its first frame is the still shown when not playing), with the
video's pixel size, duration and whether it has audio, as one undo entry "Import Video"
And a file without a video track is refused with "This file has no video" and the document is unchanged
Test level: integration

## S13-AC8 — Each frame goes through the one renderer
Given an animated document with image or video content
When the frame at time t is produced for preview or export
Then it equals `Renderer.render(document:)` of the document whose transform is `transform(at: t)` and whose content
is the still image or the video's frame at t (the last frame holds after the video ends)
Test level: integration

## S13-AC9 — Export plan
Given canvas sizes and export options
When the video export plan is computed
Then the shorter side is 720 / 1080 / 1440 px for 720p / HD / 2K, both sides are even and ≤ 4096 px, the frame
count is round(duration × fps) (≥ 1), the format is `.mp4` with the chosen codec, and a see-through backdrop gives
HEVC with alpha in `.mov`
Test level: unit

## S13-AC10 — MP4 export (H.264 and HEVC, 30 and 60 fps)
Given an animated document of about 1 s
When it is exported as H.264 at 30 fps and as HEVC at 60 fps
Then each file opens with AVFoundation, has one video track with the planned dimensions, codec and frame rate, the
planned number of frames and a duration within one frame of the plan
Test level: integration

## S13-AC11 — Exported frames match the renderer
Given an exported animation
When its first and last frames are decoded
Then they match `Renderer.render` of the start and end transforms within codec tolerance (mean channel difference
≤ 6/255)
Test level: integration

## S13-AC12 — Transparent video
Given a backdrop that is see-through (None, a translucent colour or backdrop opacity < 100 %)
When the animation is exported
Then the file is a `.mov` whose video track is HEVC with alpha, and a transparent pixel of the canvas decodes with
alpha below 10 %
Test level: integration

## S13-AC13 — Audio passthrough and mute
Given video content with an audio track
When it is exported unmuted
Then the movie has an audio track covering the export
And when the document is muted (M / the speaker button) the movie has no audio track
Test level: integration

## S13-AC14 — Progress and cancel
Given an export in progress
When progress is reported
Then it rises monotonically from 0 to 1, rendering runs off the main thread, and frames go through a pixel-buffer
pool (no per-frame buffer allocation)
And when the export is cancelled it stops within one frame, deletes the partial file and throws a cancellation;
the document is unchanged
Test level: integration

## S13-AC15 — Bounded memory
Given a 1080p export of 6 s at 60 fps (360 frames)
When it runs
Then memory stays bounded: the footprint never rises more than 768 MB above the footprint before the export (keeping
every frame would need > 2.5 GB; CoreGraphics / CoreImage keep bounded caches of render buffers that rise and fall,
see S14)
Test level: integration

## S13-AC16 — Saved with the document
Given a document with an animation timeline and video content
When it is saved as a `.sunshot` package and reopened
Then the timeline (clips, easing, durations, holds, mute, export options) is unchanged and the video's original
bytes are in `media/` and play again
And a package whose video file is missing fails with the missing-media error (or, with placeholders allowed,
opens with the still frame)
Test level: integration

## S13-AC17 — Playback preview
Given Animate mode with a timeline
When Play is pressed (or Space)
Then the playhead advances in real time, each preview frame is rendered by `Renderer.render` at preview scale, and
playback stops at the end with the playhead at the end; Pause keeps the playhead where it is; Home/End seek
And seeking renders the frame at the playhead without changing the document or the undo history
Test level: unit

## S13-AC18 — Menus
Given the menu bar
When it is built from `MenuCatalog`
Then it lists Animate (⇧⌘M), Import Video… (⌥⌘I) and Export Video… (⌃⌘E), and no shortcut is used twice
Test level: unit

## S13-AC19 — Animate mode UI
Given content in the window
When Animate is turned on
Then a glass timeline strip replaces the bottom toolbar with Exit, Mute, Add Animation, Play/Pause, the current /
total time, the clip track (one chip per clip, width ∝ duration, selected clip highlighted, jump cuts marked) and
Delete; the selected clip's Transition popover offers the six easings with curve previews, Duration and Hold sliders
and the target's position, zoom, rotation and tilt
And Export Video… opens a sheet with Resolution, Frame rate and Codec pickers, read-only Resolution, Duration and
Format rows, and a progress bar with Cancel Render while exporting
Test level: app-smoke

## S13-AC20 — Playback smoothness
Given a 1080p canvas with tilt animation on this Mac
When it plays in the preview
Then motion looks smooth (no visible stalls longer than ~100 ms) and Space toggles play/pause while the timeline has
focus
Test level: manual

## Open questions
- Should clips be free-positioned on the ruler with gaps (drag to move) instead of playing back to back? Decided:
  back to back with a per-clip hold; "move" reorders. Gaps are made with the hold.
- Video jump cut (splitting the video content itself) and dynamic backgrounds that follow the video's colours are
  not in this slice; "jump cut" here is a zero-duration clip.
- Video trimming / cropping of the media track is deferred (S10 owns crop).
