# S16 — Menu bar quick capture, default style & studio journey — acceptance criteria

Sunshot keeps running in the menu bar so the capture shortcut always works. A shortcut capture is copied to the
clipboard already styled with the user's **default style** (a whole `Project` minus per-image parts: annotations,
animation, screenshot layout), saved from the studio with **Save as Default Style**. New documents start from the
default style, and captures opened in the studio start in Annotate mode. Capture Window picks windows by hovering
them on screen, like the system screenshot. A document shows either its screenshot or its code snippet; the
toolbar's **Screenshot | Code** switch moves between them and keeps the other side.

## S16-AC1 — Defaults and settings
Given a fresh install
Then the global shortcut (⌥⇧⌘4) is on and copies with the default style, the menu bar icon is shown and captures
opened in the studio start in Annotate mode; each can be changed in Settings ▸ Menu bar & quick capture and the
choices are saved; a raw "Copy to clipboard" saved by a build from before styled copies existed becomes
"Copy with default style" once (choosing raw again afterwards is kept)
Test level: unit

## S16-AC2 — Styled clipboard capture
Given Settings ▸ After a shortcut capture is "Copy with default style"
When an area or a window is captured with the shortcut or from the menu bar
Then the clipboard holds a PNG of the capture rendered with the default style (the default template's style when
none is saved) through the one `Renderer.render`, at one canvas pixel per captured pixel; the open document is
unchanged, and a capture that fails or is not permitted copies nothing
Test level: unit

## S16-AC3 — Save as Default Style
Given a document in the studio
When Save as Default Style is chosen (Export button menu)
Then its style and layout are saved (without annotations, animation or screenshot layout) and used for quick
captures, File ▸ New, Start Over and launch; they survive relaunch; Settings shows when it was saved and Clear
forgets it; an unreadable or newer-version file is ignored
Test level: unit

## S16-AC4 — Hover to pick a window
Given Capture Window (menu bar, toolbar, File menu)
Then every screen gets a clear overlay; the front-most window under the pointer is tinted and outlined with its
app, title and size; a click captures it, a click on the desktop or Esc cancels, Space switches to area capture
(and Space in area capture switches back); Sunshot's own windows, windows without a frame and tiny helper windows
are not offered
Test level: unit

## S16-AC5 — The studio opens in Annotate mode
Given "Open captures in Annotate mode" is on
When a capture is opened in the studio (shortcut set to Open in Sunshot, Capture … into Studio, File ▸ Capture …)
or the studio is opened from the menu bar with content
Then Annotate mode is on (when the content can be annotated)
Test level: unit

## S16-AC6 — Screenshot ⇄ Code
Given a document with a screenshot
When the toolbar switch goes to Code, then back to Screenshot
Then the code snippet shows (an empty one the first time) and the screenshot comes back with its crop and
annotations, and the snippet is kept for the next switch; each switch is one undo step; New Code Snippet keeps the
screenshot too; Screenshot with no image shows the empty "drop an image" state
Test level: unit

## S16-AC8 — The annotation bar is always there
Given a document showing a screenshot (not in Animate mode, not a code snippet)
Then the annotation bar sits at the top of the canvas without entering Annotate mode first; picking a tool from it
enters Annotate mode with that tool (the sticker tool opens its picker); Done leaves the mode and the bar stays;
style choices (colour, size, line style, fill) can be set before drawing; when the content can't be annotated yet
(device mockup, moved or rotated screenshot) the bar shows disabled
Test level: unit

## S16-AC9 — Set as Default in the inspector
Given a document in the studio
When Set as Default (pinned under the inspector) is clicked
Then the document's style and layout are saved as the default style (as Save as Default Style, S16-AC3), so the
next shortcut capture is copied to the clipboard already styled without opening the studio; the button shows
Default Style (disabled) while the document's style matches the saved default (annotations don't count) and
Set as Default again once it differs
Test level: unit

## S16-AC10 — macOS screenshots get no frame
Given an image taken with the macOS screenshot tool (its EXIF comment is "Screenshot"), which already shows its
window's own title bar
When it is opened, dropped or pasted into the studio, or styled for the clipboard (S16-AC11)
Then the frame is set to None in the same undo step as the import; other images keep the document's frame
Test level: unit

## S16-AC11 — Style macOS screenshots on the clipboard
Given Settings ▸ "Style macOS screenshots on the clipboard" is on (default)
When the macOS screenshot tool copies a screenshot to the clipboard (⌃⌘⇧3/4, or ⌘⇧5 set to Clipboard)
Then within half a second the clipboard holds that screenshot rendered with the default style (S16-AC3), frame
None, through the one `Renderer.render`, and the "copied" bubble shows; only a clipboard holding a single PNG
marked as a macOS screenshot is touched (images copied from apps, files, mixed contents and Sunshot's own copies
are left alone), and a newer copy made while rendering wins; turning the setting off stops it
Test level: unit

## S16-AC12 — Annotations over the backdrop
Given a single flat screenshot (not moved, rotated or tilted, no device mockup, no screenshot layout)
When an annotation is drawn partly or wholly outside the screenshot
Then it shows over the backdrop in preview and export, on top of the content, frame and effects, without the
content's shadow; redactions still only change the screenshot's pixels; device mockups, screenshot layouts and
moved content keep annotations on their screenshot
Test level: unit

## S16-AC13 — No double backdrop when a styled copy is pasted into the studio
Given a styled copy on the clipboard (a shortcut capture copied with the default style, or a macOS screenshot
styled by S16-AC11)
When it is pasted into the studio
Then the studio gets the original captured pixels (Sunshot keeps them beside the styled PNG on the clipboard,
under its own type that other apps ignore), so the document's backdrop is drawn once; a macOS screenshot still
gets frame None; other apps paste the styled PNG
Test level: unit

## S16-AC14 — Pick a screenshot on the canvas and delete it
Given a screenshot layout with two or more images (S15), flat (moved, zoomed or rotated is fine; tilted is not)
When one of the screenshots is clicked on the canvas
Then it is outlined with a × button at its top-right corner; Delete (or ⌦, or the × button) removes it as one undo
step "Remove Screenshot" and the layout shrinks to fit (S15); Esc or a click on the backdrop clears the pick; a
drag still moves the whole layout; a slot showing the main image (no image of its own) can't be picked
Test level: unit

## S16-AC15 — Reorder a picked screenshot by dragging it
Given a screenshot picked on the canvas (S16-AC14)
Then besides its × it shows a move handle at its top-left corner; dragging the picked screenshot (or its handle)
onto another screenshot outlines that one and, on release, swaps their places as one undo step "Move Screenshot",
the moved screenshot staying picked; a release on the backdrop or on itself changes nothing; the main screenshot
only swaps with one that has an image; with nothing picked a drag moves the whole layout as before (and a drag
off the picked screenshot clears the pick and moves the layout)
Test level: unit

## S16-AC16 — The inspector keeps its width
Given any window size the studio allows and any inspector section open
Then the inspector stays 292 pt wide with its margin to the window edge: controls that want more room (the
Effects buttons) shrink instead of widening it, and Set as Default sits below the scrolling sections, never over them
Test level: manual

## S16-AC7 — In the running app
Given the running app
Then the menu bar icon shows the menu (captures, Open Studio, default-style status, Settings, Hide Menu Bar Icon,
Quit); closing the studio window keeps Sunshot running in the menu bar without a Dock icon and the shortcut still
copies styled captures with a "copied" bubble; Open Studio brings the window back; hiding the icon while the
window is closed brings the studio forward; the hover picker highlights windows on every display in Light and Dark; the annotation bar sits at the top of the
canvas clear of the screenshot and Set as Default is visible under the inspector without scrolling; a ⌃⌘⇧4 screenshot pastes styled without a
frame; an arrow drawn from the screenshot out onto the backdrop shows whole; clicking a screenshot of a layout
shows its outline and ×, and Delete removes it
Test level: manual
