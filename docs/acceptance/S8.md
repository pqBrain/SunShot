# S8 — Backdrop effects & auto backgrounds — acceptance criteria

Conventions: effects live in the document next to the backdrop (`BackdropSettings.effects`) and are part of undo. Four groups: **Adjust** `{blur 0…50 px, noise 0…100 %, saturation 0…200 %, opacity 0…100 %}` (defaults 0 / 0 / 100 / 100), **Pattern** `{kind: none | circles | waves | dots | rays | grid | stripes | noise, intensity 0…100 %, thickness 25…300 %, colour}` (defaults none / 20 % / 100 % / #23232B), **Vignette** `{style: none | dark | light, spread 0…100 %, intensity 0…100 %}` (defaults none / 50 % / 50 %), **Overlay** `{texture: none | blinds | window | leaves | lattice | ripples | dapple, opacity 0…100 %, position: above | below content}` (defaults none / 30 % / above). All lengths are canvas pixels at 1× (the render scale multiplies them), so an effect looks the same at every export size. Every effect is computed by Sunshot (no bitmap textures ship) and is deterministic, so preview and export are byte-identical. Auto backgrounds are Sunshot-generated wallpaper recipes (base gradient + soft colour fields) built from a 6-colour palette extracted from the content.

## S8-AC1 — Effects are off by default and change nothing
Given a new document, or any document saved before S8
When it is rendered
Then the effects are all at their defaults and the output is byte-identical to the S1–S4 render (every existing snapshot reference is unchanged)
Test level: snapshot

## S8-AC2 — Effects decode tolerantly and round-trip
Given project JSON without an `effects` key, or with only some effect keys, or with out-of-range values
When it is decoded
Then missing values take their defaults, out-of-range values are clamped to their ranges, and encoding then decoding returns an equal project
Test level: unit

## S8-AC3 — Adjustments apply to the backdrop only
Given a backdrop with blur, noise, saturation and opacity changed
When rendered
Then the content pixels are unchanged and only backdrop pixels differ from the unadjusted render
Test level: snapshot

## S8-AC4 — Blur is resolution-independent
Given an image backdrop with blur 12 px
When rendered at 1× and 4×
Then hard edges in the backdrop are softened (the edge transition is ≥ 12 px wide at 1×)
And the 4× render downscaled to 1× matches the 1× render (SSIM ≥ 0.97)
And a solid backdrop is unchanged by blur
Test level: snapshot

## S8-AC5 — Noise is deterministic film grain in canvas units
Given noise 60 %
When rendered twice, and at 1× and 4×
Then both renders are byte-identical, the backdrop shows per-canvas-pixel grain (non-zero variance on a solid colour) whose mean stays within 2 levels of the colour
And the 4× grain cells are 4×4 pixels (same pattern, scaled), and noise 0 adds nothing
Test level: unit

## S8-AC6 — Saturation and opacity
Given saturation 0 % then 200 %, and opacity 50 %
When rendered
Then saturation 0 makes every backdrop pixel grey (R = G = B ± 1), 200 % increases the chroma of a coloured backdrop
And opacity 50 % halves backdrop alpha (export keeps alpha), while the preview shows the checkerboard under the translucent backdrop and the export does not
Test level: unit

## S8-AC7 — Pattern kinds
Given the pattern picker
When it is opened
Then it lists eight options in this order: None, Circles, Waves, Dots, Rays, Grid, Stripes, Noise
And each pattern renders differently from every other one and from None, and matches its snapshot
Test level: snapshot

## S8-AC8 — Pattern intensity, thickness and colour
Given a pattern
When intensity, thickness or colour change
Then intensity 0 % changes nothing, a higher thickness covers more pixels, and the drawn pattern pixels take the chosen colour
Test level: unit

## S8-AC9 — Vignette
Given vignette dark or light
When rendered
Then dark darkens the corners and leaves the centre unchanged, light lightens the corners
And a larger spread reaches further towards the centre, intensity 0 % changes nothing, and snapshots match
Test level: snapshot

## S8-AC10 — Overlay textures are Sunshot's own, procedurally generated
Given the overlay picker
When it is opened
Then it lists None plus six textures in this order: Blinds, Window, Leaves, Lattice, Ripples, Dapple, each with a thumbnail drawn by the same renderer
And each texture renders differently from the others and matches its snapshot, and no bitmap texture is shipped
Test level: snapshot

## S8-AC11 — Overlay above or below the content
Given an overlay texture
When position = above
Then it shades the content as well as the backdrop
When position = below
Then content pixels are untouched and only the backdrop is shaded
And opacity 0 % changes nothing
Test level: unit

## S8-AC12 — Preview/export parity with every effect on
Given blur, noise, saturation, opacity, a pattern, a vignette and an overlay all on
When the preview render and the exported PNG are compared at 1× and 2×
Then they are byte-identical, and a 2× render downscaled to 1× matches the 1× render (SSIM ≥ 0.97)
Test level: integration

## S8-AC13 — Render budget with every effect on
Given 3712×2032 content, an image backdrop and every effect on (blur 24 px)
When rendered at 4K (3840 × 2160)
Then the render completes in ≤ 500 ms median of 10 on Apple silicon (release)
Test level: integration

## S8-AC14 — Palette extraction from the content
Given content images
When the auto palette is extracted
Then it has exactly six colours ordered by prominence, the result is deterministic
And a four-colour image yields those four colours among the six (each within 8 levels), transparent pixels are ignored
And a one-colour image yields six distinct tints/shades of that colour, and a fully transparent image yields no palette
Test level: unit

## S8-AC15 — Auto suggestions are generated mesh gradients
Given content with a palette
When the Auto block is shown
Then it shows the palette strip and five generated backgrounds, each built only from palette-derived colours, opaque, deterministic for the same palette and shuffle value, with thumbnails drawn by the same renderer
And choosing one selects the Image type with that recipe as one undo entry "Apply Auto Background"
Test level: unit

## S8-AC16 — Shuffle
Given content with a palette
When Shuffle is pressed
Then a new shuffle value is derived deterministically from the current one, a different set of five suggestions is produced and the first one is applied, as one undo entry "Shuffle Auto Backgrounds"
And undo restores the previous backdrop and suggestions; with no content Shuffle does nothing
Test level: unit

## S8-AC17 — Every effect edit is undoable and resettable
Given any effect control
When it changes
Then the change is one named undo step (a slider drag is one step), Reset in each effect popover restores that group's defaults, and Reset Backdrop also resets every effect
Test level: unit

## S8-AC18 — Effects subsection in the inspector
Given the Backdrop section
When it is shown
Then an "Effects" subsection has four glass buttons (Overlay, Adjust, Pattern, Vignette) that open popovers with the controls above; a button shows when its effect is on
And the Auto block shows the palette strip, the five suggestions and a Shuffle button
And VoiceOver reads each control with its value ("Blur, 12 pixels", "Pattern, Dots", "Auto background 2 of 5")
Test level: app-smoke

## S8-AC19 — Visual review
Given the running app in Light and Dark
When a tester tries every pattern, vignette and overlay on a few backdrops
Then the effects look tasteful (no banding, no visible tiling seams, overlays read as soft light and shadow) and the popovers use the glass look of the inspector
Test level: manual

## Open questions
- Ranges and defaults (blur ≤ 50 px, thickness 25–300 %, pattern colour #23232B at 20 %) are Sunshot's own choices; the Designer may tune them without changing the ACs' structure.
- Auto backgrounds are stored as generated wallpaper recipes in the Image type (decided: no new backdrop kind, so saved documents and other slices need no new case).
- Blur is a three-pass box blur (≈ Gaussian) on the CPU, chosen for determinism over Core Image's GPU path.
