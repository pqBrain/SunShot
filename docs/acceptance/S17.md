# S17 — Studio polish, app icon & more global shortcuts — acceptance criteria

The studio gets simpler: one saved style (the **default style**, Set as Default) instead of a separate theme
library, centred pickers, an annotation bar the user can hide, and messages that are never covered by the
Position / Crop bar. Sunshot gets its own app icon, and Open Studio and Capture Window get global shortcuts of
their own, recorded in Settings like Capture Area's.

## S17-AC1 — One saved style: no Themes pane
Given the studio
Then the left sidebar offers Layouts and Templates only (no Themes pane, no "Save current style as theme");
the default style saved with Set as Default is the one saved style (the theme library and its files are no longer
read); documents saved with a theme still open with their style
Test level: unit

## S17-AC2 — Centred pickers
Given the studio
Then the sidebar's Layouts | Templates picker is centred in the sidebar, and the toolbar's Screenshot | Code switch
sits in the middle of the toolbar
Test level: manual

## S17-AC3 — Show or hide the annotation bar
Given a document showing a screenshot
Then the annotation bar shows by default (also after relaunch); the toolbar's Annotate button hides it (leaving
Annotate mode) and shows it again; picking a tool from the bar still enters Annotate mode with that tool
Test level: unit

## S17-AC4 — Messages are never covered
Given a document with content (the Position / Crop bar or the Animate timeline shows at the bottom)
When a message shows (for example "Saved as your default style" or a crop that can't be made)
Then it sits above the bottom bar and can be read in full
Test level: unit

## S17-AC5 — App icon
Given the built app
Then Sunshot has its own icon (Finder, Dock, About, Settings) at every standard size, drawn by Sunshot's own
script (no third-party artwork), and the app bundle stays within its size budget
Test level: unit

## S17-AC6 — Open Studio and Capture Window shortcuts
Given Settings ▸ Menu bar & quick capture
Then Capture Area, Capture Window and Open Studio each have a global shortcut that can be turned on or off and
recorded (Restore Default resets it); defaults are Capture Area ⇧⌘S, Capture Window ⇧⌘W and Open Studio ⇧⌘0;
a shortcut already used by another of the three is refused with the reason; the choices survive relaunch;
pressing one anywhere runs it (Capture Window follows "After a shortcut capture" like Capture Area), and the menu
bar menu shows each one's keys
Test level: unit

## S17-AC7 — Layout thumbnails for code snippets
Given a document showing a code snippet
Then the Layouts pane previews every layout with the snippet and its style (rendered by the one `Renderer.render`),
as it does for a screenshot; editing the code refreshes them
Test level: unit

## S17-AC8 — Short Clear on the annotation bar
Given the annotation bar
Then its clear button reads "Clear" (VoiceOver and the tooltip still say "Clear Annotations"; the Edit menu keeps
"Clear Annotations")
Test level: unit

## S17-AC9 — Backdrop fits the inspector
Given the inspector
Then the Backdrop card is as wide as the other cards: its None | Solid | Gradient | Image picker shares the
column's width instead of overflowing both edges
Test level: manual

## S17-AC10 — Frame chrome in proportion to the screenshot
Given a window, card, stack or thick-border frame
Then its chrome (title bar, toolbar, traffic lights, padding) keeps its size for content up to 1440 px wide and
grows in proportion beyond it, so a Retina capture's title bar is as tall as it was on screen; the UI scale still
applies on top, and the content is never scaled
Test level: unit
