# S19 — Stack 3 & 4, dark cards, freeze capture — acceptance criteria

## S19-AC1 — Stack 3 and Stack 4 frames
Given frames stack 3 and stack 4 on content 800×500
Then they draw three and four cards behind the front card (offsets 12, 24, 36, 48 px; scales 96, 92, 88, 84 %; opacities
70, 45, 30, 18 %), all inside the frame box, and appear after Stack 2 in the frame picker
Test level: unit

## S19-AC2 — Dark cards
Given a card or stack frame with Chrome set to Dark
Then the card is drawn in the dark window colour; Light and Auto keep the Background token
Test level: snapshot

## S19-AC3 — Freeze capture marks
Given the frozen screen and a drag with the arrow, rectangle, pen or highlighter tool
Then a mark of that kind is made from the drag (arrows and rectangles from start and end, pen and highlighter from the
whole path); a click makes none and the area tool makes none; keys V A R P H pick the tool
Test level: unit

## S19-AC4 — Freeze capture result
Given the frozen display image, a selected area and marks, all in display points
Then the result is the area at the display's pixel density with the marks drawn on it in the right place; without marks it
is the plain crop; an empty area fails
Test level: unit

## S19-AC6 — Adjusting the selection
Given a selected area on the frozen screen
Then each of its four edges and four corners can be dragged to resize it (within the display, never flipping or below the
minimum size), and a drag that starts anywhere else still draws a mark
Test level: unit

## S19-AC5 — Frozen overlay
Given the capture shortcut or File ▸ Capture Area…
Then the screen is grabbed at once and shown frozen with a toolbar of tools and colours; dragging an area with the area
tool selects it and the overlay stays open so it can be marked up (⌘Z undoes a mark; V drags a new area; dragging any of the four edges or corners resizes it, so the capture never has to be redone); ⌘C copies the
area with its marks and the default style applied (always, whatever Settings ▸ After a shortcut capture says) and leaves capture mode; the Studio button or Return leaves capture mode, opens the studio and puts the same
image in it; Esc cancels; a second press while freezing is ignored
Test level: manual

## S19-AC7 — Open at login
Given Settings ▸ General ▸ Menu bar & quick capture
Then "Open Sunshot at login" registers or removes Sunshot as a login item, shows the system's state (so removing it in
System Settings turns the toggle off), and says when the system still needs the user's approval
Test level: unit
