# S3 — Backdrop basics: none / solid / gradient / image — acceptance criteria

Conventions: backdrop is one of `none | solid(color) | gradient(spec) | image(ref)`. Default = solid #EDEDF2 (from S1). Colours are stored as sRGB RGBA 8-bit-per-channel-or-better. Gradient spec = `{kind: linear|radial, angle: 0…360°, stops: [(position 0…1, colour)]}` with 2…12 stops.

## S3-AC1 — Backdrop type selector
Given a document with content
When the Backdrop section of the inspector is opened
Then a four-option selector None / Solid / Gradient / Image is shown with the current type selected
And choosing a type switches the preview and creates one undo entry "Change Backdrop Type"
And each type remembers its last-used settings during the session (switching Solid → Gradient → Solid restores the previous solid colour)
Test level: unit

## S3-AC2 — None backdrop is transparent in export
Given backdrop = none and a content PNG
When the canvas is exported as PNG
Then every pixel outside the content shape has alpha = 0
And the exported file keeps an alpha channel
And content pixels keep their original alpha
Test level: snapshot

## S3-AC3 — Checkerboard shown in preview only
Given backdrop = none
When the preview is displayed
Then a checkerboard (8 pt squares, two neutral greys adapted for Light/Dark) is drawn behind the canvas
And the exported PNG and the Copy PNG bitmap contain no checkerboard pixels
And the render function takes a flag `showsTransparencyGrid` that only the preview sets, with the rest of the pipeline identical
Test level: unit

## S3-AC4 — Solid swatch set
Given backdrop = solid
When the swatch grid is shown
Then it offers at least 24 Sunshot swatches grouped as neutrals (≥ 6, incl. black and white) and hues (≥ 18), loaded from a bundled JSON resource
And selecting a swatch sets the backdrop colour exactly to its hex value and marks it selected
And no two swatches share the same hex value
Test level: unit

## S3-AC5 — Custom colour picker for solid
Given backdrop = solid
When the user picks a custom colour via the system colour picker or types a HEX value `#1A2B3C`, `1A2B3C`, `#1a2b3c80`
Then the backdrop colour becomes that value (the 8-digit form sets alpha 0x80)
And invalid HEX input (`#12`, `ZZZZZZ`, empty) is rejected, the field reverts, and no undo entry is created
Test level: unit

## S3-AC6 — Colour with alpha over transparency
Given solid backdrop #FF0000 at alpha 50 %
When exported as PNG
Then backdrop pixels equal (255, 0, 0, 128 ± 1) un-premultiplied, and the preview shows the checkerboard through it
Test level: snapshot

## S3-AC7 — Gradient preset set
Given backdrop = gradient
When the preset grid is shown
Then at least 16 Sunshot gradient presets (linear and radial mixed) are listed from bundled JSON, each with a thumbnail rendered by the same gradient renderer
And selecting a preset replaces the gradient spec fully (kind, angle, stops) and is one undo entry
And preset names and values are unique and contain no third-party branding
Test level: unit

## S3-AC8 — Linear gradient angle semantics
Given a linear gradient from #000000 (0) to #FFFFFF (1) on a 1000×1000 canvas
When angle = 0°, 90°, 180°, 270°
Then 0° runs bottom→top, 90° left→right, 180° top→bottom, 270° right→left (pixel at the start edge ≈ #000000, end edge ≈ #FFFFFF, ±2 per channel)
And angle input outside 0…360 is normalised (−90 → 270, 450 → 90)
And a 45° snapshot on a non-square 1600×900 canvas covers the full canvas with the first stop at one corner and the last at the opposite corner
Test level: snapshot

## S3-AC9 — Radial gradient
Given a radial gradient with stops #FFFFFF (0) and #000000 (1)
When rendered on 1000×600
Then the centre pixel ≈ #FFFFFF and the farthest corner ≈ #000000 (±2)
And the radial centre stays at the canvas centre
Test level: snapshot

## S3-AC10 — Gradient stop editing
Given a gradient with 2 stops
When the user adds a stop by clicking the stop bar at position 0.5, drags it to 0.8, changes its colour, and deletes it
Then each action is one undo entry ("Add Gradient Stop", "Move Gradient Stop", "Change Stop Colour", "Delete Gradient Stop")
And a new stop's colour is the interpolated colour at that position
And stops are always kept sorted by position and positions are clamped to 0…1
And deleting is disabled when only 2 stops remain, and adding is disabled at 12 stops
Test level: unit

## S3-AC11 — Stops at identical positions and degenerate gradients
Given two stops at position 0.5 with different colours, or all stops with the same colour
When rendered
Then the result is a hard edge at 0.5 (first below, second above) or a flat fill respectively, with no NaN, crash or visible banding artefact
Test level: unit

## S3-AC12 — Gradient banding avoidance
Given a 3840×2160 linear gradient between two close colours (#202020 → #282828)
When exported
Then dithering is applied: the output contains per-pixel variation within ±1 level so that no horizontal band of constant value is wider than 8 px along the gradient axis (the span has only 8 distinct levels over 3840 px)
Test level: snapshot

## S3-AC13 — Image backdrop from a user file
Given backdrop = image
When the user chooses a PNG, JPEG, HEIC, TIFF or WebP file (picker or drop onto the backdrop well)
Then the image is used as backdrop with "fill" scaling (aspect-preserving cover, centred) so the whole canvas is covered
And the original bytes are stored in the document model as a media reference
And an unreadable file shows "Can't use this image as a backdrop" with no state change
Test level: integration

## S3-AC14 — Image backdrop scaling for every aspect ratio
Given a 4000×1000 and a 1000×4000 backdrop image on canvases of 1128×728 and 728×1128
When rendered
Then no empty (uncovered) pixels exist, the image centre aligns with the canvas centre, and the result matches snapshots
Test level: snapshot

## S3-AC15 — Bundled wallpaper set
Given backdrop = image
When the built-in wallpaper list is displayed
Then at least 8 Sunshot-generated wallpapers are listed, produced by Sunshot's own generator (no downloaded or third-party artwork)
And the total bundled wallpaper payload is ≤ 3 MB
And selecting one sets the backdrop and is undoable
And a repository check confirms each wallpaper has a generator seed/recipe file as provenance
Test level: unit

## S3-AC16 — Reset backdrop
Given a customised gradient (or any type)
When "Reset Backdrop" is pressed
Then backdrop returns to the default (solid #EDEDF2)
And it is a single undo entry, and pressing it when already at default adds no entry
Test level: unit

## S3-AC17 — Every backdrop mutation is undoable
Given the document store
When type, swatch, custom colour, gradient preset, angle, kind, stops, image and reset are each applied
Then undo/redo walks back and forth over all of them and the model after redo-all is equal to the model before undo-all
Test level: unit

## S3-AC18 — Preview/export parity and scale independence
Given each backdrop type (none, solid, gradient, image)
When preview and export render at 1× and 2×
Then same-scale outputs are byte-identical across both paths
And gradient and image backdrops at 2× are proportionally identical to 1× (SSIM ≥ 0.98 after resizing)
Test level: unit

## S3-AC19 — Large image backdrop memory and 4K timing
Given an 8000×8000 image backdrop and an 8000×8000 content image
When exported at 1×
Then peak memory growth ≤ 2 GB and no crash
And a 3840×2160 canvas with a 4000×3000 image backdrop renders in ≤ 500 ms median on Apple silicon (backdrop decode cached after first use)
Test level: integration

## S3-AC20 — Accessibility and appearance
Given the Backdrop section
When used with VoiceOver, keyboard-only, in Light and Dark
Then each swatch has a label (colour name or hex, selected state), each gradient preset a label ("Gradient preset <name>"), stops are focusable with arrow keys to move by 0.01 (⇧: 0.1)
And all controls are reachable by Tab and meet contrast requirements in both appearances
Test level: app-smoke

## Open questions
- Gradient angle convention (0° = bottom→top, clockwise) is an assumption; Designer to confirm.
- Whether the solid colour picker is the native `NSColorPanel` or a custom in-popover picker (AC5 holds for either).
- Whether an image backdrop needs fit/fill/tile options (assumed fill only in this slice; effects such as blur are S8).
- Eyedropper and stop-flip tools from the reference are not required in S3.
